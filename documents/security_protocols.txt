# Security Protocols

## Access Control
- Role-based access control (RBAC) enforced at all layers
- Multi-factor authentication required for admin accounts
- Just-in-time access for privileged operations
- Session timeout after 15 minutes of inactivity

## Data Protection
- AES-256 encryption for data at rest
- TLS 1.3 for data in transit
- PII detection and masking in logs
- Regular data retention policy enforcement

## Incident Response
1. Detection: Automated alerting via Azure Monitor
2. Containment: Network isolation and access revocation
3. Eradication: Root cause analysis and patch deployment
4. Recovery: Verified restore from backup
5. Lessons learned: Post-incident review within 48 hours

## Compliance
- SOC 2 Type II certified
- GDPR compliant for EU data subjects
- HIPAA ready for healthcare workloads
- Regular third-party security assessments
